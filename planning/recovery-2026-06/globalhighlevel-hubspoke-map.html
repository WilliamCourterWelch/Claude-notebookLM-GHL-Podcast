02 — CALEB'S RULES (from the course)

How authority + silos actually work

AUTHORITY

Only editorial body links pass juice. Nav/footer/sidebar ≈ 0. And only the first link to a URL on a page counts.

NAV

Don't put pages you want to rank in the nav — the nav link gets crawled first and wastes the pass. Link them from body content instead.

STRUCTURE

3 tiers: Topic (pillar) → Variations (15) → Supporting. Each topic = one silo.

WITHIN A SILO

Topic links down to all variations; every variation links back up; variations form a link circle (V1→V2→V3→V1).

SILO INTEGRITY

Never cross-link between different silos. Topic 4's variation must not link to Topic 1. This is the strict rule.

NOFOLLOW

Don't sculpt with nofollow — Google penalizes it, and total link count divides the authority anyway. Internal links = external links.

04 — THE HONEST GAP

Your silos are 1-page stubs

Caleb's model wants each Topic to have ~15 variations forming a link circle. You have 15 posts total — so most silos are a single pillar with no variations yet. The interlinking structure is right, but it only gets powerful once each money silo (Pricing, Payments, Trial) has its variations built out. For this first slice: set the silo skeleton, link the homepage to the topic pillars by body links (not nav), and drive conversion through the affiliate CTA. Then build variations into the silos that matter (Pricing, Trial, the Spanish cluster).
