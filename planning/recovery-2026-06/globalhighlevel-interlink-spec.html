Interlinking Spec · Caleb Ulku method · executable

The corrected linking rules for the build.

Replaces the earlier "funnel everything to the trial blog" approach. Per Caleb: isolated silos, no cross-silo links, rank pages out of the nav, and conversion through the external affiliate CTA.

01 — THE 6 BUILD RULES

How every page links

1

Nav = no rank pages

The menu holds only Home, About, Language switch, and the trial CTA button. No topic/money pages in the nav — nav links pass ~0 authority and burn the "first link" slot.

2

Homepage = apex, links by body

The homepage links down to each topic pillar through body content (not the menu). It's the only page that spans topics — apex → pillars.

3

Trial blog = standalone silo

The free-trial blog gets one internal link, from the homepage. No other silo links sideways into it. It still ranks for "gohighlevel free trial" on its own.

4

CTA button → GHL (external)

Every page's "Start 30-day trial" button is an external affiliate link to gohighlevel.com (fp_ref + UTM, nofollow noopener). External = silo-safe + one hop to the money.

5

Inside a silo: topic ↔ variations + link circle

Topic pillar links to all its variations; each variation links back up; variations form a circle (V1→V2→V3→V1). All body links.

6

Never cross-link silos

A pricing-silo page never links to a payments-silo page. Spanish is its own microsite — joined to English only by the language switch + hreflang.

02 — THE MONEY PAGE, REWIRED

Free-trial blog: from cross-linked to standalone

✕ Now (wrong per Caleb)
  • 11 inbound links — 8 from different silos (pricing, phone, SMS, payments, CRM, sites) cross-linking sideways into it
  • Links out to /category, /services, and 3 other-silo blog posts
  • Visitor path: blog post → internal trial-blog link → then out to GHL (two hops)
✓ After (Caleb-correct)
  • 1 inbound link — from the homepage (apex → pillar) only
  • No cross-silo links in or out; the category/services links removed
  • Visitor path: any page → CTA button → GHL direct (one hop = better conversion)
03 — WHAT CHANGES IN THE BUILD

Concrete edits

build.py — homepage block EDIT
  • Body links to each topic pillar (Pricing, Payments, Phone, SMS, CRM, Sites) + one link to the free-trial blog. The trial CTA button → GHL affiliate.
build.py — every blog post template EDIT
  • Replace the internal "start trial" links with the external GHL CTA button. Remove cross-silo links; keep only same-silo links (to the pillar / sibling variations).
build.py — nav/footer REMOVE
  • Drop topic/money pages and /category/agency-platform/ from the nav. Nav = Home · About · Español/English · [Start trial →].
_redirects ADD
  • 301 the thin category pages to their topic pillar (same as before). Category leaves nav + sitemap.
/es/ silo MIRROR
  • Same rules inside the Spanish microsite: /es/ apex → ES pillars (opiniones, precios, qué-es, pagos); CTA → GHL; no links into the English silos.
💰 The conversion engine: one button, on every page, every language — gohighlevel.com/highlevel-bootcamp?fp_ref=amplifi-technologies12 + UTM, target=_blank rel="nofollow noopener". That's what makes money. The internal links just build topical authority within each silo; they don't carry the sale.
