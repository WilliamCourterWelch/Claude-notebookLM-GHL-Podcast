01 — WHAT THE SERP SHOWED

The existing pages are topic content, not audience content

Example SERPs (page-1 competitors): stop spam calls → GHL docs + Reddit + Kixie. payment providers → GHL docs + ghlelite + unisonpayment. build website → GHL docs + YouTube. None split agency vs business owner. So forcing these into an "agency hub" or "service hub" would be fake. They sort by topic (Caleb's original silo model), not audience.

So the structure is: topic silos hold the existing feature how-tos; the audience hubs (service / agency) are populated by NEW spokes whose keyword is audience-specific (ai-receptionist = service; white-label = agency). The homepage "Which are you?" routes people to the right mix.
